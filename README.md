# 每日书单

每天自动从 100 本书库里挑 **5 本不同类别**的书，各生成 **3 张 1080×1440** 的图文卡片，发布成一个手机能打开的页面。

**不调用任何 AI 画图模型**：全部视觉由 HTML/CSS + 无头浏览器渲染，零图像 Token。

## 每天自动发生什么

- 北京时间 **08:00**（UTC 00:00）由 GitHub Actions 触发
- 挑选 5 本（类别不重复，轮完 100 本才重复）
- 出 15 张图 → 生成手机版页面 → 发布到 GitHub Pages
- 链接固定，每天内容滚动更新

## 打开

`https://<你的用户名>.github.io/douyin-booklist/`

手机上直接看，支持一键复制标题和文案。

## 红线

本仓库**只生成图片和网页**：

- 不登录抖音
- 不上传任何内容
- 不发布任何内容

## 手动跑一次

Actions → 每日书单 → Run workflow。

## 换书单

编辑 `data/books.json`，字段说明：

```json
{
  "id": "001",
  "t": "被讨厌的勇气",
  "a": "岸见一郎 / 古贺史健",
  "c": "心理",
  "p": ["所谓成熟", "是敢被人讨厌"],
  "s": "自由不是想做什么就做什么，是不怕别人怎么看你。",
  "q": "一切烦恼，都是人际关系的烦恼。",
  "qt": "原文",
  "e": "你烦的不是事，是事里的人。",
  "fit": "总在讨好别人的人"
}
```

改完后 `node scripts/validate.mjs` 应显示「校验通过」。

## 本地预览

```bash
node scripts/generate.mjs --count 5
node scripts/make-mobile.mjs
# 打开 output/<日期>/mobile/index.html
```

需要本机有 Edge 或 Chrome（用于截图）。
